Way of the Mouse is a Way from Menagerie. It allows you to play a cheap Action
card ($2 or $3) which was set aside at the beginning of the game, and is
different from any of the other cards used in the game. It is therefore a Way
that can be different from one game to the next.

## Official FAQ

- Set aside any unused non-Duration Action kingdom card costing $2$2 or $3$3
  at the start of the game.
- Do any setup that that card requires.
- When using Way of the Mouse, you play the set-aside card, leaving it
  set-aside. For example, if you set aside Sleigh, then any Action card could be
  used to gain 2 Horses.
- The set-aside card cannot move itself when played, since it is not in play;
  for example, if the card is Ratcatcher (from Adventures), it won't move to the
  Tavern mat.
- Text on the set-aside card below a dividing line (other than setup) will
  not do anything.

## Other rules clarifications

- You cannot use Way of the Mouse when playing the card set aside by Way of
  the Mouse, to prevent loops that could matter with Champion.

## card text

Play the set-aside card, leaving it there.

Setup: Set aside an unused non-Duration Action costing $2 or $3.
