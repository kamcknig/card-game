Sword is a Treasure-Attack-Loot card from Plunder. Like most other Loot cards, it provides +$3 and +Buy; its
distinguishing feature is that it is also a mild handsize attack.

## Official FAQ

This is an Attack, and so cards like Moat and Shield protect from it.

## card text

$3
+1 Buy
Each other player discards down to 4 cards in hand.
