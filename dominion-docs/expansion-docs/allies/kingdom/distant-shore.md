Distant Shore is an Action-Victory-Odyssey card from Allies. It is a Laboratory
variant that gains Estates.

It is part of a split pile that it shares with the other Odysseys: Old Map,
Voyage, and Sunken Treasure.

## Official FAQ

- Gaining an Estate isn't optional.
- If the Estate pile is empty you still get +2 Cards and +1 Action.

## card text

+2 Cards

+1 Action

Gain an Estate.

2VP
