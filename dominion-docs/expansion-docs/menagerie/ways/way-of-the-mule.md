Way of the Mule is a Way from Menagerie. It allows you to use any Action as a
source of disappearing money similar to a Copper.

## Official FAQ

- Way of the Mule is considered so simplistic, that it does not have an
  official FAQ.

## Other rules clarifications

- For those who care about order of events, you gain +1 Action first, then +$1

## card text

+1 Action

+$1
