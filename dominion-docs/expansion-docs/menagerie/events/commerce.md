Commerce is an Event from Menagerie. It allows you to gain a Gold per
differently named card you've gained in a turn.

## Official FAQ

- First count how many differently named cards you have gained this turn,
  then gain that many Golds. For example, if you have gained two Provinces, a
  Silver, and a Horse, you would gain three Golds.

## card text

Gain a Gold per differently named card you've gained this turn.
