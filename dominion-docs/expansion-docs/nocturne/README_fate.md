# Fate

Fate is a card type that was introduced in Nocturne. Fate cards give out Boons.

## Official Rules

- Nocturne has Fate cards and Boons.
- Fate cards can somehow give players Boons; all the Fate type means is that
the Boons are shuffled at the start of the game.

## List of Fate cards

- $2 Druid, Pixie, Tracker
- $3 Fool
- $4 Bard, Blessed Village
- $5 Idol, Sacred Grove
