Rice is a Treasure card from Rising Sun. It rewards you with $ for having a large number of card types in play.

## Official FAQ

- For example, if you had a Daimyo, a Litter, a Fishmonger, three Coppers, and Rice in play, the types would be Action,
  Command, Shadow, and Treasure, so Rice would make +$4.

## card text

+1 Buy

+$1 per different type among cards you have in play.
