# Dominion Card Game

A browser-based, real-time multiplayer implementation of the Dominion deck-building card game. Play with friends online — no download or installation required.

## What Is Dominion?

Dominion is a deck-building card game where each player starts with a small identical deck and races to acquire the most victory points before the supply runs out. On each turn you draw a hand of cards, play action cards to gain advantages, buy new cards to strengthen your deck, and discard everything for the next turn. The player with the most victory points at the end wins.

Visit the [Dominion Strategy Wiki](https://wiki.dominionstrategy.com/index.php/Main_Page) for a full overview of rules and strategy.

## Features

- **Real-time multiplayer** — play with others in the same match simultaneously, with live board updates as each action resolves
- **Account system** — persistent accounts with secure login; accounts are invitation-based via registration codes
- **Match lobby** — create or join matches, configure the kingdom before the game starts
- **Configurable kingdoms** — choose which expansion cards appear in a match, or let the game randomly pick a kingdom
- **Full rules engine** — card interactions, reactions, and edge cases are enforced automatically
- **16 expansions supported** — see the full list below
