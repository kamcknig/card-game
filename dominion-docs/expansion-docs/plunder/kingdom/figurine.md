Figurine is a Treasure card from Plunder. Unlike most Treasure cards, it
provides +Cards. If you draw more Treasures, you can play them; if you draw
Action cards, you probably can't, but Figurine allows you to discard one
for +$1 and +Buy.

## Official FAQ

This is a Treasure, and so is played in your Buy phase, but draws cards.
This means that usually if it draws you an Action card, that card won't be
useful that turn, except that Figurine itself lets you discard one Action card
for +1 Buy and +$1.

## card text

+2 Cards

You may discard an Action card for +1 Buy and +$1.
