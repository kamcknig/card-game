Importer is an Action-Duration-Liaison card from Allies. It is a gainer that can
gain $5 cards, but delays when you get them. It also changes the setup for
Favors/Liaisons so that players start with a total of 5 Favors, rather than 1;
but unlike other Liaisons, it provides no way of acquiring additional Favors
beyond the ones you start with.

## Official FAQ

- At the start of the game, each player gets five Favors instead of one.
  Importer doesn't provide a way to get any more Favors during the game.

## card text

At the start of your next turn, gain a card costing up to $5.

Setup: Each player gets +4 Favors.
